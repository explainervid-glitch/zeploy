Activity

    Add package

    Pick a folder that contains zdeploy.json, or a .zip made by zdeploy pack. You can also drag a .zip onto this window.

    Connect a team PC

    Install the agent once per PC. After that it starts hidden every time the PC's user signs in.

    With the installer

    1. Save the installer to a folder the team PC can open, such as a folder on the file share.

    2. On the team PC, sign in as the person who uses it. They must be a local administrator. Double-click Install zdeploy agent.cmd and choose Yes when Windows asks.
    3. The PC appears here within a few seconds.

    The installer contains the team token. Save it where only the team can open it, and delete it once the PCs are set up.

    Set up with a command instead
    1. Copy zdeploy-agent.exe to a local folder on that PC, such as Downloads. Don't run it from a network drive: an administrator terminal can't see drives like Z:.
